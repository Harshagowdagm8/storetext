# storetext
Secure Text Pad is a lightweight web application that allows users to securely save and access text notes using a custom password. Developed with HTML, CSS, and JavaScript, it stores data in the browser's Local Storage. Users can create, save, and view notes only after entering the correct password, ensuring basic privacy and easy note management.
Project Description: Secure Text Pad (CodedPad)

Secure Text Pad is a simple web-based application that allows users to store text notes securely using a custom password. Users can enter any text, set a password, and save the content. The saved text can only be viewed by entering the correct password.

The application is developed using HTML, CSS, and JavaScript and uses the browser's Local Storage to save data. It provides a simple and user-friendly interface for creating and accessing password-protected notes without requiring a database or server.

Features
Create and save text notes.
Set a custom password for each note.
Password verification before viewing stored text.
Simple and responsive user interface.
Data stored locally in the browser.
Technologies Used
HTML
CSS
JavaScript
Browser Local Storage
Objective

The main objective of this project is to provide a lightweight and easy-to-use platform for storing personal notes securely with password protection while demonstrating the use of client-side web technologies.
